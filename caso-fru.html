An information system for monitoring and evaluation

Design and implementation of a monitoring system built on an information system that supports the organization’s MEAL processes.

The challenge

The challenge was to automate the monitoring of activities. The organization had records in digitized attendance forms and a platform called Araguaney, but the two did not communicate with each other. A time-consuming manual verification process had to bridge that gap.

What I built

1 · Sources

Digitized attendance forms
Araguaney platform

Deduplication

3 · Use

MEAL information system
Power BI dashboards
  • A monitoring system, built on an information system, that connects the digitized attendance forms with the Araguaney platform and replaces manual verification.
  • Team training in filling in the forms, to put the processes into operation.
  • Capacity building within the team so it could automate its own processes.
  • Record deduplication so that each person is counted only once.
  • Data audit and quality protocols on the system.

Results

Efficiency

The data systematization process became faster.

Quality

Record deduplication and data quality audit protocols.

Capacity

The team developed its own capacity to automate its monitoring processes.

For confidentiality reasons, no data or dashboards with beneficiary information are published. I can present the system in a conversation.
